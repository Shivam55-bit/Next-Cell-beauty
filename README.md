# NEXT CELL BEAUTY - Fullstack Ecommerce Platform

Full-featured e-commerce storefront, admin panel, and REST API backend for NEXT CELL BEAUTY.

## Architecture
- **Storefront**: React 19, Vite, Tailwind CSS, Redux Toolkit, Lucide React
- **Admin Panel**: `next-cell-beauty-admin` (React, Vite, Admin Dashboard)
- **Backend**: `next-cell-beauty-backend` (Node.js, Express, MongoDB / Mongoose, JWT Auth, Swagger)

## Getting Started

### 1. Storefront (Root)
```bash
npm install
npm run dev
```

### 2. Admin Panel
```bash
cd next-cell-beauty-admin
npm install
npm run dev
```

### 3. Backend Server
```bash
cd next-cell-beauty-backend
npm install
npm run dev
```
